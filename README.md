Como usar
Crie um repositório com o mesmo nome do seu usuário do GitHub.
Crie um arquivo README.md.
Cole o código acima.
Troque SEU_USUARIO pelo seu nome de usuário do GitHub.

O resultado terá:

📊 Barras de estatísticas
📈 Gráfico de contribuições
🔥 Streak de commits
🐍 Cobrinha animada
🚀 Ícones de tecnologias
🌙 Tema moderno com animações visuais
